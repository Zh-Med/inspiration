# GPU 减负 · 2026-11-14

用户反馈：M2 Mac 上页面卡顿，GPU 占用约98%。这是用户观察，尚未通过进程级性能采样确认全部占用来自该网页。

## 本次改变

- 原先每张可见纸页都有9px背景模糊，呼吸高光又通过screen混合与brightness滤镜参与叠层。现在仅最前纸页保留6px模糊，后层保留原香槟金透明渐变；转场快照取消实时模糊。可能的视觉差异是后层透叠边缘更清晰，须真机对照。
- 呼吸图层原RGB经brightness(2)已饱和到白色，改为预先写入白色渐变，移除额外滤镜与screen混合。几何、透明度曲线、6秒周期、1秒渐亮／1秒保持／约0.918秒回落、0.19秒错峰及左侧增强仍保留。
- 离屏纸页不渲染；只在移动时给可见页will-change，避免大量工具条目长期占用合成层。拖动及惯性仍使用原requestAnimationFrame循环，未加入低帧率限流。
- 星空保持原星数、冷暖色、透视深度与运动速度。6种星光纹理与面光源纹理初始化一次，替代逐帧构造渐变；背景画布上限约150万像素、DPR最高1.5，仅影响星空，不降低文字／纸页分辨率。
- 环境动画调度上限24fps，阅读背景18fps；玻璃灯光12Hz。实际帧率受屏幕刷新与负载影响。高光通过固定纹理平移；玻璃底色角度固定，不再每帧重画渐变方向。
- 窗口失焦、页面隐藏、Reduce Motion、离开相关路由时停循环；转场期间使用静态星空和暂停的呼吸快照。品牌呼吸使用opacity，避免持续改文字颜色。

## 检查与限制

17项测试通过；新增模拟时钟检查画布预算、星光纹理复用、动画频率上限、后台停帧、恢复不重复创建循环、阅读与转场路由。

以1512×982 CSS像素、DPR2为例，旧星空画布5,939,136像素，新约1,500,000像素，画布面积减少约75%。390×844上保留DPR1.5，画布面积比DPR2减少约44%。这些是工作量边界计算，**不是GPU占用或电量实测**。

## 真机复核

先关闭旧页面与重复标签，重新打开已更新页面，分别观察总览停留20秒、News书架停留20秒、连续拖动、文章阅读。比较同一窗口大小／同一页面的GPU趋势，同时检查纸页透叠、呼吸峰值、星点清晰度、返回转场与Reduce Motion。手机另测发热、手感、离线重开。

可在开发控制台只读调用 `ScenePerformance.snapshot()` 查看背景绘制次数、画布像素、调度上限与活动状态；不采集或上传设备数据。若某个场景仍明显偏高，应针对该场景继续采样，不能以全机GPU数字直接认定唯一根因。
